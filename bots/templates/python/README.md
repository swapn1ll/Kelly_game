# Python bot template

A starter bot: `choose_bet` returns 0 until you write your strategy. Two helpers are
ready to use: `my_chance` (your chance of winning a round) and `max_bet` (20% of your money).

Copy this whole folder to `bots/<your-name>/` and edit only the section marked
`EDIT ONLY THIS SECTION` in `bot.py`. A working example (plain Kelly) is in `bots/samples/`.
See the main README, "Writing a bot".
